# प्रश्न 25 — विस्तृत हल

> **अध्याय 9: किरण प्रकाशिकी एवं प्रकाशिक यंत्र** &nbsp;|&nbsp; श्रेणी: **मान ज्ञात करना**
> &nbsp;|&nbsp; अंक: **2** &nbsp;|&nbsp; विषय: **क्रान्तिक कोण से अज्ञात अपवर्तनांक**

---

## 📋 प्रश्न

किसी पारदर्शी पदार्थ से वायु की सीमा पर क्रान्तिक कोण 30° है। पदार्थ का वायु के सापेक्ष अज्ञात अपवर्तनांक ज्ञात कीजिए।

---

## 🧮 प्रयुक्त सूत्र

```
sin C = 1/n;    n = 1/sin C
```

## 🤔 यह सूत्र क्यों लगाया?

क्रान्तिक अवस्था में विरल वायु में अपवर्तन कोण 90° होता है। स्नेल नियम से पदार्थ का अपवर्तनांक क्रान्तिक कोण के sine का व्युत्क्रम मिलता है।

---

## ✍️ चरणबद्ध हल

### चरण 1 — मान

C = 30° होने से sin C = 1/2।

### चरण 2 — अपवर्तनांक

n = 1/sin30° = 1/(1/2) = 2.0।

### चरण 3 — अर्थ

बड़ा n छोटे क्रान्तिक कोण के अनुरूप है; पदार्थ वायु से पर्याप्त प्रकाशिक सघन है।

---

## ✅ उत्तर

> **पदार्थ का अपवर्तनांक n = 2.0 है।**

---

## 🎯 परीक्षा की ट्रिक

सूत्र वायु के लिए n<sub>air</sub> ≈ 1 मानकर है। दो सामान्य माध्यम हों तो sin C = n<sub>rarer</sub>/n<sub>denser</sub> लिखना सुरक्षित है।

---

## 🔄 वैकल्पिक विधि / अतिरिक्त ध्यान

स्नेल रूप n sin30° = 1×sin90° लिखें; इससे n = 2 बिना सूत्र याद किए भी निकाला जा सकता है।
