# प्रश्न 25 — विस्तृत हल

> **अध्याय 7: प्रत्यावर्ती धारा** &nbsp;|&nbsp; श्रेणी: **मान ज्ञात करना**
> &nbsp;|&nbsp; अंक: **2** &nbsp;|&nbsp; विषय: **धारिता ज्ञात करना**

---

## 📋 प्रश्न

50 Hz पर किसी संधारित्र का धारितीय प्रतिघात 31.8 Ω है। उसकी धारिता ज्ञात कीजिए।

---

## 🧮 प्रयुक्त सूत्र

```
X_C = 1/(2πfC)    ⟹    C = 1/(2πfX_C)
```

## 🤔 यह सूत्र क्यों लगाया?

संधारित्र का AC विरोध धारिता के व्युत्क्रमानुपाती है। दिए X<sub>C</sub> और f से सम्बन्ध पलटकर C प्राप्त होगा।

---

## ✍️ चरणबद्ध हल

### चरण 1 — C अलग करें

C = 1/(2πfX<sub>C</sub>)।

### चरण 2 — मान रखिए

C = 1/(2π × 50 × 31.8) F।

### चरण 3 — गणना

C ≈ 1.001 × 10⁻⁴ F।

### चरण 4 — μF में

C ≈ 100.10 μF ≈ 100 μF।

---

## ✅ उत्तर

> **धारिता C ≈ 100.10 μF, अर्थात् लगभग 100 μF।**

---

## 🎯 परीक्षा की ट्रिक

X<sub>C</sub> के सूत्र में C हर में है। C अलग करते समय X<sub>C</sub> फिर भी हर में ही रहता है।

---

## 🔄 वैकल्पिक विधि / अतिरिक्त ध्यान

100 μF मान जाँचने पर X<sub>C</sub> = 1/(2π × 50 × 100 × 10⁻⁶) ≈ 31.83 Ω मिलता है।
