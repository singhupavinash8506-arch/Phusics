# प्रश्न 17 — विस्तृत हल

> **अध्याय 4: गतिमान आवेश और चुम्बकत्व** &nbsp;|&nbsp; श्रेणी: **सूत्र आधारित**
> &nbsp;|&nbsp; अंक: **2** &nbsp;|&nbsp; विषय: **धारा सुग्राहिता**

---

## 📋 प्रश्न

किसी चल-कुण्डली गैल्वेनोमीटर में N = 100 फेरे, A = 0.01 m², B = 0.5 T तथा ऐंठन नियतांक C = 10⁻⁶ N·m/rad है। इसकी धारा सुग्राहिता ज्ञात कीजिए।

---

## 🧮 प्रयुक्त सूत्र

```
धारा सुग्राहिता = θ/I = N A B / C
```

## 🤔 यह सूत्र क्यों लगाया?

सन्तुलन में विक्षेपक बल आघूर्ण (NIAB) प्रत्यानयन बल आघूर्ण (Cθ) के बराबर होता है, अतः θ = (NAB/C) I। इस अनुपात को धारा सुग्राहिता कहते हैं।

---

## ✍️ चरणबद्ध हल

### चरण 1 — सन्तुलन की शर्त

N I A B = C θ  ⟹  θ/I = N A B/C

### चरण 2 — अंश

N A B = 100 × 0.01 × 0.5 = 0.5

### चरण 3 — भाग

θ/I = 0.5/10⁻⁶

### चरण 4 — गणना

= 5 × 10⁵ rad/A

---

## ✅ उत्तर

> **धारा सुग्राहिता = 5 × 10⁵ rad/A**

---

## 🎯 परीक्षा की ट्रिक

सुग्राहिता बढ़ाने के उपाय — N बढ़ाइए, A बढ़ाइए, B बढ़ाइए अथवा C <b>घटाइए</b> (पतला निलम्बन तार लीजिए)। C हर में है, अतः उसे घटाना है।

---

## 🔄 वैकल्पिक विधि / अतिरिक्त ध्यान

<b>वोल्टता सुग्राहिता</b> = θ/V = NAB/(CR) होती है। ध्यान दें — धारा सुग्राहिता बढ़ाने पर वोल्टता सुग्राहिता आवश्यक रूप से नहीं बढ़ती (यदि R भी बढ़ जाए)। यह सूक्ष्म बिन्दु पूछा जाता है।
