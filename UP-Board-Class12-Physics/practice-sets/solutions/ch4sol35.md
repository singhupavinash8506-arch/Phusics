# प्रश्न 35 — विस्तृत हल

> **अध्याय 4: गतिमान आवेश और चुम्बकत्व** &nbsp;|&nbsp; श्रेणी: **मान ज्ञात करना**
> &nbsp;|&nbsp; अंक: **3** &nbsp;|&nbsp; विषय: **परिनालिका — n तथा कुल फेरे**

---

## 📋 प्रश्न

50 cm लम्बी परिनालिका में 5 A धारा बहने पर भीतर क्षेत्र 6.28 × 10⁻³ T है। <b>प्रति मीटर फेरे तथा कुल फेरों की संख्या</b> ज्ञात कीजिए।

---

## 🧮 प्रयुक्त सूत्र

```
n = B/(μ₀ I);   N = n × L
```

## 🤔 यह सूत्र क्यों लगाया?

पहले n निकलता है (क्षेत्र तथा धारा से), फिर लम्बाई से गुणा करके कुल फेरे। यह क्रमिक विधि है।

---

## ✍️ चरणबद्ध हल

### चरण 1 — प्रति मीटर फेरे

n = B/(μ₀ I) = (6.28 × 10⁻³)/(4π × 10⁻⁷ × 5)<br>= (6.28 × 10⁻³)/(6.283 × 10⁻⁶) ≈ <b>1000 फेरे/मीटर</b>

### चरण 2 — मात्रक बदलिए

L = 50 cm = 0.50 m

### चरण 3 — कुल फेरे

N = n × L = 1000 × 0.50

### चरण 4 — गणना

N = <b>500 फेरे</b>

---

## ✅ उत्तर

> **n = 1000 फेरे/मीटर तथा N = 500 फेरे**

---

## 🎯 परीक्षा की ट्रिक

B परिनालिका की <b>लम्बाई</b> पर निर्भर नहीं करता, केवल n पर। अतः लम्बाई का प्रयोग केवल कुल फेरे निकालने में होता है — क्षेत्र निकालने में नहीं।

---

## 🔄 वैकल्पिक विधि / अतिरिक्त ध्यान

यदि कुल फेरे N तथा लम्बाई L दी हो तो पहले n = N/L निकालकर B = μ₀nI लगाइए। सीधे N रखना सबसे आम भूल है।
