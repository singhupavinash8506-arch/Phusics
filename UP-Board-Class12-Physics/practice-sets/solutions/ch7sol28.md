# प्रश्न 28 — विस्तृत हल

> **अध्याय 7: प्रत्यावर्ती धारा** &nbsp;|&nbsp; श्रेणी: **मान ज्ञात करना**
> &nbsp;|&nbsp; अंक: **2** &nbsp;|&nbsp; विषय: **अनुनादी धारिता ज्ञात करना**

---

## 📋 प्रश्न

0.10 H प्रेरकत्व वाले श्रेणी LCR परिपथ को 50 Hz पर अनुनादी बनाना है। आवश्यक धारिता ज्ञात कीजिए।

---

## 🧮 प्रयुक्त सूत्र

```
f_0 = 1/(2π√(LC))    ⟹    C = 1/[(2πf_0)²L]
```

## 🤔 यह सूत्र क्यों लगाया?

अनुनाद पर प्रेरणिक और धारितीय प्रतिघात समान होते हैं। दी गई L और लक्ष्य आवृत्ति से उसी शर्त को C के लिए हल किया जाता है।

---

## ✍️ चरणबद्ध हल

### चरण 1 — कोणीय आवृत्ति

ω<sub>0</sub> = 2πf<sub>0</sub> = 2π × 50 ≈ 314.16 rad/s।

### चरण 2 — धारिता सूत्र

C = 1/(ω<sub>0</sub>²L)।

### चरण 3 — मान रखिए

C = 1/[(314.16)² × 0.10] F।

### चरण 4 — गणना

C ≈ 1.0132 × 10⁻⁴ F = 101.32 μF।

---

## ✅ उत्तर

> **आवश्यक धारिता C ≈ 101.32 μF।**

---

## 🎯 परीक्षा की ट्रिक

f<sub>0</sub> पूरे वर्ग में आता है। 2πf को केवल एक बार लिखकर वर्ग भूलना बड़ी संख्यात्मक त्रुटि देगा।

---

## 🔄 वैकल्पिक विधि / अतिरिक्त ध्यान

X<sub>L</sub> = 2πfL ≈ 31.416 Ω निकालकर C = 1/(2πfX<sub>L</sub>) लगाने पर वही 101.32 μF मिलता है।
