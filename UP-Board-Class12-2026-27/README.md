# UP Board (UPMSP) Class 12 — Syllabus 2026-27 & Model Papers

Official documents downloaded from the Uttar Pradesh Madhyamik Shiksha Parishad (**UPMSP**) website, <https://upmsp.edu.in>, on **21 September 2026**.

Source pages:

- Syllabus — <https://upmsp.edu.in/Board_Syllabus.aspx> (tab *Class 12* and *Class 12 Trade*)
- Model papers — <https://upmsp.edu.in/Board_ModelPaper.aspx> (tab *Class 12*)

## Read this first

| | Session printed on the documents | Status |
|---|---|---|
| **Syllabus** (98 PDFs) | **2026-27** | Current — this is what you study this year |
| **Model / sample papers** (23 PDFs) | **2025-26** | Latest the board has published |

The syllabus is exactly what you asked for: 95 of the 98 syllabus PDFs carry the header *“शैक्षिक सत्र 2026-27”* (Academic Session 2026-27); the remaining three (Computer, Ranjan Kala, NCC) simply omit the session line but are from the same Class 12 set.

**The model papers are a different story.** UPMSP has **not yet released a 2026-27 set** — the only Class 12 model papers on their site are still stamped *प्रतिदर्श प्रश्नपत्र 2025-26 / Sample Question Paper 2025-26*. Those are the ones included here. They are still worth practising from, because the syllabus and marking scheme barely changed, but check <https://upmsp.edu.in/Board_ModelPaper.aspx> again later in the session for the 2026-27 papers.

Also note: UPMSP has **no question bank for Class 12** (only Class 9), so none is included.

## Two things to know about the PDFs

1. **Hindi text won't copy-paste properly.** The Hindi-medium PDFs use the legacy Krutidev/Chanakya font encoding, so selecting text gives gibberish like `“kSf{kd l=&2026&27`. They display and print perfectly fine — it only affects copying and text search.
2. **One file on the board's site is mis-named.** Their model paper `132-Home-Science.pdf` is actually code **135, Home Science** (code 132 is Military Science) — the PDF says `कोड-135 गृह विज्ञान` inside. It has been renamed to `135-Home-Science.pdf` here so it lines up with the syllabus. Nothing else was altered; every PDF is byte-for-byte as published.
